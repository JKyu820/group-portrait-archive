# 阶段一 · 26 人排布自测

在 Windows 本地预览中使用 Chrome 和 Edge 加载网页。每个视口逐一点选 26 位人物的脸部中心，再运行 5 组编号和名称搜索。桌面以鼠标操作，触控视口使用浏览器的触屏模拟。

| 浏览器与视口 | 结果 |
| --- | --- |
| Chrome 1440 × 900、912 × 720 | 通过 |
| Edge 1024 × 768 | 通过 |
| Chrome 触控 900 × 780、768 × 1024、600 × 800、390 × 844、320 × 568 | 通过 |

## 检查结果

- 26 张独立 SVG 均成功加载，合影中的人物下方无文字标签。逐个点选后，资料面板的编号和图片与选中人物对应。
- 全角编号、三位编号、查找名称和多条匹配均可查找。点击结果或按 Enter 能定位到目标，无结果时显示提示。
- 同一时刻只有一个人物处于选中状态，其余 25 人变暗。关闭资料、点舞台空白或使用「返回全体」可恢复合影，清空搜索也会取消选中。
- 桌面显示右侧名片。窄屏滚动到目标人物，使其脸部位于底部面板上方。
- 各测试视口未出现页面横向溢出。测试过程中未观察到浏览器控制台错误、页面异常或失败的资源加载。
- TypeScript 检查和生产构建均通过。

## 验收边界

手机结果来自触控模拟，iOS Safari 和安卓真机体验仍待验收。短屏上的完整资料可以在面板内滚动。26 张测试图共用一个适合当前轮廓的点击范围。换用正式 PNG 后，应根据图像留白和前后排遮挡复核点击区域。
